# Ocean Rescue Game

Un minijuego interactivo construido con React y Tailwind CSS.

## Descripción

**Ocean Rescue Game** es un juego simple y divertido donde:
- ¡Debes atrapar la basura marina para sumar puntos! (+10 puntos por cada basura)
- ¡Evita tocar a los peces y algas! (-5 puntos por cada contacto)
- Tienes 30 segundos para conseguir la máxima puntuación

## Características

- ✅ Animación suave de los elementos
- ✅ Sistema de puntuación dinámico
- ✅ Temporizador de 30 segundos
- ✅ Interfaz responsiva con Tailwind CSS
- ✅ Emojis para una experiencia visual divertida

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

El juego se abrirá en `http://localhost:5173`

## Build para producción

```bash
npm run build
```

## Componentes

- **OceanRescueGame**: Componente principal del juego
- **App**: Contenedor principal

## Tecnologías

- React 18
- Tailwind CSS
- Vite
